    CONTAINER CONCEPTS IN THIS PROJECT

    Units III & IV

    Persistent storage

    SQLite stores tasks in /data/tasks.db; the named Docker volume keeps them when a container is replaced.

    Networking

    Compose creates an isolated bridge network. Port mapping publishes container port 5000 on host port 5000.

    Security

    The image runs as an unprivileged user. Runtime settings come from the environment, and inputs use parameterized SQL.

    Optimization

    A multi-stage Dockerfile installs dependencies in a builder stage and copies only the virtual environment and app into runtime.

    Automation

    The GitHub Actions workflow builds the image on pushes and pull requests, catching packaging errors early.

    Monitoring & Kubernetes

    /health checks the app and database. Kubernetes deployment and service examples are in k8s/.
